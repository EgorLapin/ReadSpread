# 📚 ReadSpread

Мультиформатная офлайн-читалка для Android, созданная как университетский проект.

## ✨ Основные возможности

*   **Чтение книг:** поддерживаются форматы **TXT**, **EPUB** и **FB2**.
*   **Управление библиотекой:** добавление книг из памяти устройства, поиск по названию и автору, фильтрация по категориям (все, избранное, читаю сейчас).
*   **Кастомизация:** пользователь может задавать свои названия книгам и менять обложки, выбирая изображения из галереи.
*   **Темы оформления:** три режима — светлый, тёмный и сепия. Выбор сохраняется.
*   **Прогресс чтения:** отслеживается в процентах и сохраняется для каждой книги.

## 🏗️ Архитектура и стек технологий

Проект построен по принципам **Clean Architecture** с использованием архитектурного паттерна **MVVM**.

*   **Язык:** Kotlin
*   **UI:** Jetpack Compose (Material 3)
*   **База данных:** Room для хранения книг, закладок и прогресса
*   **Внедрение зависимостей:** Hilt
*   **Асинхронность:** Kotlin Coroutines и Flow
*   **Навигация:** Compose Navigation
*   **Изображения:** Coil
*   **Хранение настроек:** DataStore (для темы)
